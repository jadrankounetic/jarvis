Wake Word

"Hej Jarvise" — stalno slušanje
Sluša u pozadini dok je aplikacija otvorena; kaži "Jarvise" da aktiviraš. Troši bateriju i podatke.
Radi samo dok je ekran upaljen i aplikacija u prednjem planu (ograničenje mobilnih preglednika — nije pravi "uvijek uključen" wake word kao kod native aplikacija). Ekran će ostati upaljen dok je ovo uključeno.

Reminders

Podsjetnike dodaješ glasom ("podsjeti me za 20 minuta da..."). Rade pouzdano dok je app otvorena; za podsjetnike sutra ili za nekoliko sati preglednik na Androidu može ugasiti tab u pozadini pa se neće oglasiti — najbolje za bliske podsjetnike (minute do par sati).

Google Calendar

Napravi na console.cloud.google.com: 1) Novi projekt → 2) Enable "Google Calendar API" → 3) OAuth consent screen (External, dodaj sebe kao test user) → 4) Credentials → Create OAuth Client ID → Web application → Authorized JavaScript origins: tvoj GitHub Pages URL (npr. https://username.github.io) → Create → kopiraj Client ID.
Status: NOT CONNECTED
Spajanje traje otprilike sat vremena po sesiji (Google ograničenje za pristup bez backend servera) — ponovi klik ako kalendar prestane raditi.

Web Search

Besplatno — 1000 pretraga/mjesec, bez kartice. app.tavily.com. Bez ovoga Jarvis ne može tražiti aktualne informacije na webu.
